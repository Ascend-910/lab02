COS10026 Unit Outline

Author: Chris Pilgrim Subject: Approved for use in 2023 Created: February 2025

Unit Description

This project-based unit focuses on developing your skills to build web applications using web technologies. You'll work individually and in teams to tackle real-world web development challenges, building proficiency in selecting and applying suitable web technologies.

Unit Learning Outcomes

  • Develop proficiency in web application architecture and design
  • Apply appropriate web technologies to solve real-world problems
  • Collaborate effectively in individual and team settings
  • Critically evaluate web technologies and frameworks

Weekly Topics & Schedule

Week 1: Introduction to Web Applications

Overview of web technologies, client-server architecture, and development environments.

Week 2: HTML & CSS Fundamentals

Semantic HTML structure, CSS styling techniques, and responsive design principles.

Week 3: JavaScript Basics

DOM manipulation, event handling, and fundamental JavaScript concepts.

Week 4: Front-end Frameworks

Introduction to modern front-end frameworks and component-based development.

Week 5: Back-end Development

Server-side programming, APIs, and database integration.

Week 6: Full-Stack Integration

Connecting front-end and back-end components, authentication, and deployment.

Week 7: Advanced Topics

Progressive web apps, performance optimization, and emerging web technologies.

Week 8: Mid-term Assessment

Evaluation of core concepts and practical skills developed Weeks 1-7.

Week 9: Project Development

Individual or team project work with guidance and support.

Week 10: Project Presentation

Final project presentations and peer review.

Week 11: Reflection & Future Directions

Reflecting on learning outcomes and exploring career opportunities in web development.

Week 12: Final Assessment

Comprehensive evaluation of all unit concepts and practical skills.

Assessments Overview

Assessment 1: Weekly Quizzes

Weight: 20% | Due: Weekly throughout the semester

Short quizzes covering weekly topics and readings.

Assessment 2: Mid-term Practical

Weight: 25% | Due: Week 8

Practical assessment demonstrating core web development skills.

Assessment 3: Final Project

Weight: 35% | Due: Week 12

Major project involving building a complete web application.

Assessment 4: Participation & Reflection

Weight: 20% | Due: Throughout the semester

Participation in discussions, peer review, and learning reflection.

Required Resources

  • Web browser (Chrome or Firefox for development)
  • Git for version control

Recommended Resources
